# OpenCV Event Tracker

## Goal
Build a configurable real-time computer-vision application that processes webcam/video input, detects and tracks relevant objects, and records meaningful events.

## Planned features
- Webcam and video-file input
- OpenCV detection/tracking pipeline
- Configurable colors/objects, regions and thresholds
- Bounding boxes and line/zone crossing events
- Event cooldown, timestamped logs and saved screenshots
- Annotated output video and FPS reporting
- Tests for non-camera components

## Portfolio objective
Demonstrate Python, OpenCV, video processing, computer vision, tracking, configurable workflows and event handling.

## Status
Planning / initial development.
